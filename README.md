# Hop Hop 그림 전송 서버

태블릿 브라우저에서 직접 그림을 그리거나 기존 이미지를 선택해 PC의 `input_sprites` 또는 `uploads` 폴더로 보내는 Flask 사이트입니다.

## 실행 방법 (Windows)

1. PC에 Python 3.10 이상을 설치합니다. 설치할 때 **Add Python to PATH**를 선택합니다.
2. `start_server.bat`을 더블 클릭합니다.
3. Windows 방화벽 창이 나오면 **개인 네트워크** 접근을 허용합니다.
4. 검은 창의 `태블릿에서 접속` 주소를 확인합니다. 예: `http://192.168.0.15:5000`
5. 같은 Wi-Fi에 연결된 태블릿의 Chrome 또는 Safari에서 그 주소를 엽니다.

서버를 끄려면 실행 창에서 `Ctrl+C`를 누르거나 창을 닫습니다.

## 태블릿에서 그리기

1. **직접 그리기** 탭에서 손가락 또는 태블릿 펜으로 그립니다.
2. 색상과 펜 굵기를 고르고, 필요하면 지우개·실행 취소·전체 지우기를 사용합니다.
3. **이 그림을 전송 목록에 추가**를 누릅니다. 그림은 768×768 투명 배경 PNG가 됩니다.
4. 그림을 더 만들거나 **파일 선택** 탭에서 기존 이미지를 추가할 수 있습니다.
5. 저장 폴더를 고르고 **PC로 전송**을 누릅니다.

## 저장 위치와 제한

- `input_sprites/`: 이후 스프라이트 생성기가 읽을 입력 이미지
- `uploads/`: 원본 또는 아직 분류하지 않은 이미지
- 허용 형식: PNG, JPG, JPEG, WEBP, GIF
- 한 요청의 전체 최대 크기: 기본 32MB

같은 이름을 여러 번 보내도 날짜·시간과 무작위 문자가 붙어 기존 파일을 덮어쓰지 않습니다. 확장자가 맞더라도 실제 이미지로 열 수 없는 파일은 저장하지 않습니다.

최대 크기를 바꾸려면 서버 실행 전에 PowerShell에서 `$env:MAX_UPLOAD_MB = "64"`처럼 설정할 수 있습니다. 포트는 `$env:PORT = "8080"`처럼 변경합니다.

## 접속되지 않을 때

- PC와 태블릿이 동일한 Wi-Fi인지 확인합니다. 게스트 Wi-Fi는 기기 간 통신을 차단할 수 있습니다.
- Windows 방화벽에서 Python의 **개인 네트워크** 통신을 허용합니다.
- VPN을 잠시 끄고 다시 시도합니다.
- 서버를 다시 실행해 새로 표시된 주소를 사용합니다.

로그인 기능이 없는 로컬 도구이므로 공용 Wi-Fi에서는 실행하지 않는 것을 권장합니다.
